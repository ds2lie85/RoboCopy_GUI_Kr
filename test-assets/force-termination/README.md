# 강제 종료 기능 시험 도우미

이 도우미는 실제 사용자 프로그램 대신 임시 시험 파일을 독점 점유하고, 정상 종료 요청을 의도적으로 거부합니다.

1. 저장소 루트에서 `build.ps1`을 실행합니다.
2. `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\test-assets\force-termination\Run-LockTestHelper.ps1`을 실행합니다.
3. 도우미 창에 표시된 원본 폴더와 대상 폴더를 RoboCopy GUI에 지정합니다.
4. 복사를 시작하고 잠금 오류가 표시되면 점유 프로세스 확인 및 안전 종료를 요청합니다.
5. 안전 종료가 실패한 뒤에만 강제 종료 버튼과 우클릭 메뉴가 나타나는지 확인합니다.
6. 강제 종료를 선택하고 붉은 경고 창에서 승인하면 도우미 프로세스가 종료되고 재시도가 성공하는지 확인합니다.

강제 종료 시험을 취소하려면 도우미 창의 **잠금 해제 후 종료** 버튼을 누릅니다. 도우미는 10분 후에도 자동으로 종료됩니다.
