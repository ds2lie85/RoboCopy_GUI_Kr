# RoboCopy_GUI_Kr 1.1

Windows x64용 한국어 Robocopy GUI의 1.1 릴리스입니다. 복사, 검증 후 이동, 단방향 백업 및 트레이 에이전트 기반 지속 동기화를 지원합니다.

2026-10-12 통합 재빌드입니다. 제품 표시 1.1, 패키지 1.1.0, 파일/어셈블리 1.1.0.0을 유지하며 이전 1.1 설치기를 현재 개발 내용으로 교체합니다. 이전 빌드와 구분할 때 배포 날짜와 SHA-256을 확인하세요.

This October 12, 2026 rebuild keeps version 1.1 (package 1.1.0; file/assembly 1.1.0.0) and integrates the fixes below with the existing Explorer and copy improvements. The release date and SHA-256 distinguish it from earlier 1.1 builds.

- Windows 11 기본 우클릭 메뉴에서 `Robocopy로 복사`를 직접 클릭할 수 있습니다. 대상 폴더 빈 공간에는 붙여넣기·이동·백업·지속 동기화 메뉴를 제공합니다.
- 설치기의 개발자 모드 활성화 옵션은 기본 미체크입니다. Windows 11 기본 메뉴 등록 목적, PC 전체 적용 및 예기치 못한 위험 경고를 표시하고 추가 확인과 관리자 승인을 거칩니다. 제거 시 개발자 모드를 자동 해제하지 않습니다. 유료 인증서나 서명 서비스는 사용하지 않습니다.
- 대량 덮어쓰기 목록을 가상화하여 UI 멈춤과 메모리 급증을 개선했습니다.
- 단일 원본은 승인된 덮어쓰기를 바로 처리합니다. 검색 등에서 선택한 여러 원본이 같은 대상 경로에 모일 때만 최종 파일을 선택합니다.
- 미니 UI에서 백업 확인 창의 Owner 오류, 읽기 전용 파일 덮어쓰기와 실패 정리 오류를 수정했습니다.
- 직접 파일 복사 실패를 요약에 포함합니다. 미니 UI 작업 종료 시 실패 또는 미해결 오류가 남으면 메인창과 오류 파일 관리 창으로 자동 전환합니다. 실패 0이나 완료 화면만으로 전체 내용 검증을 의미하지 않습니다.
- 잠금 조회가 원본만 검사하던 문제를 수정해 원본·대상 모두 검사합니다. 현재 앱이 사용하는 EXE/DLL을 식별하고, 자기 실행 파일의 반복 재시도 대신 정상 종료 후 별도 위치에서 실행하는 조치 방법을 안내합니다.
- 하위 동기화 작업의 대상 전용 항목을 최상위 대상 경로 기준으로 한 번 확인합니다. 모두 유지한 결정도 기억하고 각 작업의 승인된 항목만 복사 성공 후 삭제합니다. 선택하지 않은 폴더를 보호하며 비재귀 작업의 하위 폴더 검사도 수정했습니다.
- 성능 측정용 임시 출력의 순간적인 공유 잠금은 제한적으로 정리 재시도합니다. 원본 데이터와 다른 폴더는 정리 범위에서 제외합니다.

Direct copy now appears in the Windows 11 primary context menu. Paste operations remain available on the destination folder background. Developer Mode is optional, unchecked by default, and requires explicit confirmation. Large conflict lists are virtualized. Only multiple sources mapping to the same destination require winner selection. The release fixes hidden-window ownership and read-only replacement errors and retains failed jobs in summary reporting.

다운로드 파일: `RoboCopy_GUI_Kr_Setup_v1.1_x64.exe`, `SHA256SUMS.txt`. 설치기는 .NET 8 Desktop Runtime이 없는 오프라인 환경을 위한 자체 포함 앱도 포함합니다. Windows 10 x64 최소 선언 기준은 빌드 14393이며 Windows 11 기본 메뉴는 Windows 11에서만 지원합니다. 서명되지 않은 설치 파일이므로 Windows 다운로드·실행 경고가 표시될 수 있습니다.

이번 재빌드 검증 환경은 Windows 10 x64 빌드 19045, .NET SDK 8.0.425입니다. 설치기의 실제 설치·제거 및 다른 컴퓨터 동작은 별도 수동 확인 대상입니다. 자동 테스트 및 빌드 결과는 DEVELOPMENT_STATUS.md를 확인하세요. 이전 빌드의 Windows 11 또는 다른 컴퓨터 확인 결과를 이번 재빌드의 검증으로 간주하지 않습니다.

Mini-window failures now open the main error manager. Lock checks include both paths and the running application's modules. Queued backup jobs share one review, including a keep-all decision, while unselected folders remain protected. The installer includes an offline self-contained payload. This rebuild is unsigned and was checked on Windows 10 x64 build 19045; installation/removal and Windows 11 checks require separate validation.
