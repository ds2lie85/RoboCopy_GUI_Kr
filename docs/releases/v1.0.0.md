# RoboCopy_GUI_Kr 1.0

The first public release provides a Korean Windows interface for Robocopy with copying, verified moves, one-way backup, and continuous synchronization through a tray agent. It includes profiles, sequential job queues, preview/analysis, main/compact windows, automatic thread recommendations, and Explorer context menus.

첫 공개 버전은 Robocopy용 한국어 Windows UI를 제공하며 복사, 검증 후 이동, 단방향 백업 및 트레이 에이전트 기반 지속 동기화를 지원합니다. 프로필, 순차 작업 큐, 미리보기·분석, 메인·미니 창, 자동 스레드 추천 및 탐색기 우클릭 메뉴를 포함합니다.

Failed files can be retried individually, including selected UAC-approved elevated retries for access-denied files. Locking processes can be inspected through Restart Manager; forced termination requires explicit approval after a normal shutdown attempt fails. Move mode deletes only source files whose copied contents have been verified.

실패 파일은 개별 재시도할 수 있으며 접근 거부 항목은 선택 후 UAC 승인으로 관리자 재시도할 수 있습니다. Restart Manager로 잠금 프로세스를 확인하며 강제 종료는 정상 종료 실패 후 명시적인 승인이 필요합니다. 이동 모드는 복사된 내용의 검증에 성공한 원본 파일만 삭제합니다.

Download `RoboCopy_GUI_Kr_Setup_v1.0_x64.exe` and compare its SHA-256 with `SHA256SUMS.txt`. The declared minimum is Windows 10 version 1607 x64 (build 14393). The installer includes an offline self-contained application, so no separate SDK installation is needed. The maintainer has confirmed successful installation and operation on another computer.

`RoboCopy_GUI_Kr_Setup_v1.0_x64.exe`를 내려받고 SHA-256을 `SHA256SUMS.txt`와 비교하세요. 최소 환경 기준은 Windows 10 버전 1607 x64(빌드 14393)입니다. 설치기는 오프라인 자체 포함 앱을 제공하므로 별도 SDK 설치가 필요하지 않습니다. 관리자가 다른 컴퓨터에서 정상 설치와 작동을 확인했습니다.

The interface is Korean and synchronization is one-way. This release does not provide Windows 7/8.1 builds or native ARM64 binaries. Refer to the README for deletion choices, quarantine behavior, and operating requirements.

UI는 한국어이며 동기화는 단방향입니다. Windows 7/8.1용 빌드 및 ARM64 네이티브 바이너리는 제공하지 않습니다. 삭제 선택, 격리 동작 및 실행 조건은 README를 참고하세요.
